# N4K48 — MyZubster Digital Identity Pilot

Profilo pubblico di **Nicola / N4K48**, collegato volontariamente al percorso **MyZubster LIFE Digital Business Pilot** e al prototipo di identità persistente per **Neon Plaza**.

## Stato attuale

**MVP definito; integrazione e validazione end-to-end in corso.**

L'obiettivo è permettere a N4K48 di autenticarsi tramite GitHub, entrare in Neon Plaza con un personaggio persistente e ritrovare lo stesso profilo dopo una nuova sessione.

## Cosa deve dimostrare l'MVP

- login GitHub verificato dal backend;
- profilo pubblico minimo con avatar o fallback neutro;
- separazione chiara tra guest e account-linked;
- nessuna email, token o segreto nel profilo pubblico;
- persistenza del personaggio tra sessioni;
- presenza condivisa verificabile in Neon Plaza.

L'identità account-linked non equivale a identità legale verificata. Una roadmap, un test o un profilo GitHub non costituiscono prova di deployment, partnership, vendita o adozione.

## Modalità di aggiornamento

Questo repository mantiene il profilo pubblico del partecipante tramite branch e pull request. Le modifiche automatiche o assistite restano soggette a revisione umana prima del merge.

Dati privati, credenziali, token OAuth e informazioni non necessarie non devono essere pubblicati.
