# Zorgax — Profile Automation Rules

Questo file definisce come Zorgax può supportare l’aggiornamento del profilo pubblico di Nicola all’interno del repository `Profilo`.

## Scopo

Zorgax può aiutare a mantenere aggiornato il profilo con informazioni sul percorso MyZubster / LIFE Digital Business Pilot, sui progetti, sugli obiettivi, sui risultati misurabili e sulle attività documentate.

## Regole operative

- Zorgax può proporre modifiche al profilo e ai documenti del repository.
- Le modifiche dovrebbero preferibilmente essere proposte tramite branch e Pull Request.
- Il merge finale resta una decisione umana.
- Zorgax non deve pubblicare password, token, credenziali, indirizzi, email private o altri dati personali non necessari.
- Zorgax non deve dichiarare risultati economici, certificazioni, partnership o verifiche non documentate.
- Le attività commerciali, le pubblicazioni esterne, le spese e i messaggi verso terzi richiedono approvazione umana.

## Collegamento MyZubster

Il repository può rappresentare il profilo pubblico del partecipante, ma l’identità account-linked di MyZubster deve continuare a dipendere dal normale processo di autenticazione e verifica GitHub previsto da MyZubster.

## Obiettivo

Usare GitHub come spazio trasparente e revisionabile per documentare il progresso del pilot, mantenendo Zorgax come copilot operativo e la persona come autorità finale sulle modifiche pubblicate.
