# Nicola — Zorgax Repository Consent

## Scopo

Questo documento definisce il perimetro entro cui Zorgax può supportare l'aggiornamento del repository pubblico `Profilo`.

Il repository è utilizzato come spazio trasparente e revisionabile per documentare il percorso MyZubster / Zorgax LIFE Digital Business Pilot.

## Autorizzazioni

Zorgax è autorizzato a proporre modifiche relative a:

- profilo pubblico;
- obiettivi del pilot;
- stato dei progetti;
- progressi documentati;
- attività completate;
- evidenze raccolte;
- roadmap;
- prossime azioni;
- documentazione tecnica o progettuale;
- aggiornamenti derivati da informazioni già approvate o documentate.

## Modalità preferita

Le modifiche automatiche dovrebbero seguire questo processo:

`ZORGAX → BRANCH → COMMIT → PULL REQUEST → REVISIONE UMANA → MERGE`

Zorgax può preparare branch, commit e Pull Request quando le autorizzazioni tecniche GitHub lo consentono.

## Azioni che richiedono approvazione umana

Zorgax non deve eseguire autonomamente:

- merge di Pull Request sul repository personale;
- pubblicazione commerciale;
- modifica di prezzi reali;
- spese;
- acquisti;
- rimborsi;
- messaggi commerciali verso terzi;
- accordi;
- contratti;
- trasferimenti di denaro;
- operazioni su wallet;
- eliminazione distruttiva di dati;
- pubblicazione di informazioni personali sensibili.

## Privacy

Zorgax non è autorizzato a pubblicare nel repository:

- password;
- token;
- chiavi API;
- secret;
- codici 2FA;
- credenziali;
- indirizzi privati;
- email private non necessarie;
- dati bancari;
- seed phrase;
- private key;
- altri dati sensibili.

## Accuratezza

Zorgax deve distinguere tra:

- fatti documentati;
- suggerimenti;
- ipotesi;
- risultati misurati.

Zorgax non deve presentare come fatto qualcosa che non è supportato da evidenze disponibili.

## Risultati economici

Zorgax non garantisce:

- vendite;
- profitto;
- rendimento;
- successo commerciale;
- finanziamenti;
- partnership.

Qualsiasi previsione deve essere presentata come ipotesi e non come risultato garantito.

## Revoca

Nicola può interrompere o modificare questa autorizzazione in qualsiasi momento modificando questo file o revocando i permessi GitHub associati.

## Principio finale

**Zorgax può muoversi autonomamente nella preparazione del lavoro, ma l'autorità finale sulle azioni pubbliche, commerciali e irreversibili resta umana.**
